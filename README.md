# Dr. Saugat Mondal — Personal Research Website

A responsive, static academic portfolio website. It uses HTML, CSS and a small amount of JavaScript and can be hosted free on GitHub Pages.

## Before publishing — important personalisation checklist

1. Replace `ADD-YOUR-PUBLIC-EMAIL` in `index.html` with your public professional email address.
2. Replace the generic Google Scholar, ORCID and LinkedIn links with your personal profile URLs.
3. Verify every publication title, author list, journal, year, page range and DOI. The publications section deliberately marks incomplete entries as placeholders; do not publish placeholders as confirmed papers.
4. Add your approved CV PDF at `assets/Saugat_Mondal_CV.pdf`. The site currently includes a link to that filename but does not include a CV file.
5. Verify the award names and public wording in the Highlights section.
6. Check all information and contact details before making the site public.

## Local preview

Open `index.html` in a web browser. For a more realistic local preview, use Visual Studio Code with the Live Server extension.

## Publish free with GitHub Pages

1. Sign in to GitHub or create an account at https://github.com/.
2. Create a **public** repository named exactly `YOUR-USERNAME.github.io` (replace `YOUR-USERNAME` with your GitHub username).
3. Upload the contents of this folder to the repository root. `index.html` must be at the root, not inside another nested folder.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, then click **Save**.
6. Wait a few minutes and open `https://YOUR-USERNAME.github.io/`. GitHub Pages can take a little time to publish the first time.
7. If it does not appear, check the repository's **Actions** tab for a Pages deployment error.

GitHub Pages documentation: https://docs.github.com/en/pages/quickstart
